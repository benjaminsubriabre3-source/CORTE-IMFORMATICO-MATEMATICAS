## Clonar repositorio 

En una nueva carpeta VACIA de cualquier nombre (el repositorio ya viene con la carpeta)
>>>copien los codigos nomas
en Visual Studio Code
1 - abrir la terminal (Ctrl + ñ)

2 - git init

3 - git clone https://github.com/benjaminsubriabre3-source/CORTE-IMFORMATICO-MATEMATICAS.git

Con eso ya deberia crearles la carpeta




## SUBIR LOS CAMBIOS

para subir los cambio al github sigan estas instrucciones.


1 - git checkout -b nombre_rama                             >>> Crean su rama y se cambian a ella automaticamente.
(pueden poner los nombres que quieran pero para mejor entendimiento prefieran usar su nombre.)

2 - git add .                                               >>> Solamente los archivos que crearon o editaron.

3 - git commit -m "Describan los cambios que hicieron"

4 - git push origin nombre_de_su_rama                       >> Los cambios se subiran a su rama personal
